Painel de produtos 👟

Aqui você consegue adicionar, editar e excluir tênis sem mexer no código. No final, clique em Baixar catálogo atualizado.

Importante: este painel funciona no seu próprio navegador. Ele não precisa de senha nem internet para editar. Para atualizar o site publicado, você só precisa substituir o arquivo produtos.js.

Produtos cadastrados

Terminou de editar?
  1. O navegador vai baixar um arquivo chamado produtos.js.
  2. Coloque esse arquivo dentro da pasta do site.
  3. Quando o Windows perguntar, escolha Substituir o arquivo.
  4. Abra o site novamente e pronto.
